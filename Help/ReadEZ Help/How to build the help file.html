How to build ReadEZHelp.chm

The program opens help pages by name (the Help ID column of Topic list.csv, in lower case, plus .htm; see Services\HelpFile.vb). Both ways below keep those names.

A. HTML Help Workshop (quickest)

  1. Open HTML Help project\ReadEZHelp.hhp in Microsoft HTML Help Workshop and select Compile (or run hhc.exe ReadEZHelp.hhp).
  2. Copy ReadEZHelp.chm to ReadEZ\Deploy.

B. HelpNDoc (to edit the manual and add pictures)

  1. Create a new project called ReadEZ Help.
  2. Import the files in Topics (File > Import > HTML files), in the order of Topic list.csv; set each topic's level from the Level column.
  3. Set each topic's Help ID to the Help ID column (HelpNDoc makes the same ID from the title, but check it) and its help context to the last column.
  4. Add screenshots of ReadEZ where useful.
  5. Build the CHM as ReadEZHelp.chm and copy it to ReadEZ\Deploy. HelpNDoc can also build the online (HTML) help; put its address in Settings > Admin > Online help.

If you change a Help ID, change it in HelpFile.vb (Pages) too.
