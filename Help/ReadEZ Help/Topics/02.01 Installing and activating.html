Installing and activating

Run ReadEZ-Setup.msi. ReadEZ is installed in Program Files\Thomson Software Solutions\ReadEZ and can be installed alongside ReadEZ 2020.

The first time ReadEZ starts it asks for your licence. If ReadEZ 2020 was activated on this computer its licence is taken over automatically. Otherwise enter the serial number (it starts RZ-) and activate online, or use the offline activation code from Thomson Software Solutions.

ReadEZ checks for updates when it starts and from Help > Check for updates. An update keeps your settings, licence, patients, tests and reading texts.
