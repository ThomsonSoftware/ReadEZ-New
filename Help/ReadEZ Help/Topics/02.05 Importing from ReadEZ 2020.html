Importing from ReadEZ 2020

ReadEZ keeps its data in a new database (Documents\ReadEZ Data\Database\ReadEZ.db). Patients, organisations, screeners, baseline tests and colour results from ReadEZ 2020 (ReadEZ2020.db) can be imported:

  • automatically: the first time ReadEZ starts, it offers to import the ReadEZ 2020 database it finds;
  • at any time: File > Import a ReadEZ 2020 database, or Settings > Data.

The old database is only read, never changed. A backup is made before importing. Importing the same database again adds only patients and tests that are new, so nothing is duplicated.

ReadEZ 2020's settings (text, timings, screens and its palette) can be imported in Settings > Admin > Maintenance from RZSettings.ini. After importing, check the ReadEZ colours again.
