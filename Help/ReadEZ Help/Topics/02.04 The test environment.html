The test environment

The test should be administered in a quiet room, free from distractions. The room lighting should be subdued and care should be taken to avoid reflections on the screen.

The patient should be seated comfortably in front of the screen with the examiner seated to one side. The screen should be viewed from approximately 40 cm and the patient should wear the spectacles that they normally use for reading (if any).

The lenses test is done in a darkened room so that the whole visual field is coloured; the computer test with the room lights on.

Before screening, confirm that the patient has had a recent eye examination by an optometrist, to rule out an ocular cause of the symptoms.
