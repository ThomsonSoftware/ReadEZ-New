Setting up the screens

ReadEZ uses two windows: the control window (what you work in) and the patient's screen (what the patient looks at). In Settings > Screens choose where each goes.

ArrangementHow it works
One screenBoth on the same monitor. During a test the text the patient reads is shown in the test screen itself; press F11 to show it full screen with a small control strip, and Esc to return.
Two screensThe patient's screen covers a second monitor (Windows display setting Extend these displays). The test screen shows an exact copy, so you can mark errors on it while the patient reads.

Also set the width and height of the patient's screen in Settings > General, then check the colours on that screen.
